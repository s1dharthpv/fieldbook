# Security policy

Fieldbook reads DocType definitions and writes nothing to your site. Only users with the System
Manager role can use it.

If you find a security problem, please do not open a public issue. Email
sidharth.thamban@gmail.com with the Frappe version, the steps to reproduce and what you saw. You will
get an answer within a few working days.

Supported versions: the latest release on the `main` branch.
